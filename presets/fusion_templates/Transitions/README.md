# Fusion Transitions

This folder contains bundled Edit-page Fusion transition templates (`.setting`).

Current bundle:

- `Dip To Color`
- `Whip Slide`
- `Flash Frame`
- `Zoom Blur`
- `Split Wipe`
- `Soft Light Leak`

These templates are discovered automatically by ResolveAIO and can be installed into Resolve's `Edit/Transitions` template folder.
